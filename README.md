# Claudio-

## Tipografía Rancho Doble

La carpeta [`tipografia/`](tipografia/) contiene la fuente de la marca (archivos
`.ttf` y `.woff2` listos para instalar o usar en web), el CSS con la paleta y las
clases del logotipo, y un muestrario visual (`tipografia/muestra.html`).

Ver [`tipografia/README.md`](tipografia/README.md) para el detalle.

## Etiquetas de cuero

La carpeta [`etiquetas/`](etiquetas/) tiene la etiqueta grabada de la marca en
los tres colores de cuero de la muestra (`etiquetas/salida/`), más la plantilla
HTML y el script que las regenera.

Ver [`etiquetas/README.md`](etiquetas/README.md) para el detalle.
